# templapyze

A greeter CLI.

```
$ uv run templapyze --name Broman --formal
Good day from templapyze to Broman!
```

Two invocation paths: `uv run templapyze ...` and `uv run python -m templapyze ...`.
Run `uv run templapyze --help` to see the options (`--name`, `--formal`).
