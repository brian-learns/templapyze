# Bootstrap log: manual templapyze run (Phase B)

Source: tpl8 tag `v0.1.0` (commit `96a6a5d`), extracted via
`git archive v0.1.0 | tar -x` — clean tree, no artifacts possible.

This log is the step-by-step record of the manual run. It is the spec and
integration-test fixture for the real `templapyze` command (Phase C).

## Steps taken

1. **Extract** — 15 files from the tag into `~/templapyze`.
2. **Excluded** — `docs/` (design docs are template-specific) and `uv.lock`
   (references the old project's own dist; regenerated by `uv sync`).
3. **Path renames** — `src/tpl8` → `src/templapyze`;
   `src/templapyze/.agents/skills/tpl8` → `.../skills/templapyze`.
4. **Token rename** — `sed 's/\btpl8\b/templapyze/g'` (word-boundary) in the
   6 files where the token occurs: `AGENTS.md`, `pyproject.toml`,
   `src/templapyze/__init__.py`, `src/templapyze/__main__.py`,
   `tests/test_greet.py`, `src/templapyze/.agents/skills/templapyze/SKILL.md`.
5. **Personalize** —
   - `description = "Bootstrap a new Python project from a template"`
   - replaced the template's `[tool.templapyze]` *manifest* table with the
     *provenance* block (`origin = "tpl8"`, `version = "0.1.0"`) — same table
     name, different fields; the generator must **replace**, never copy
   - authors kept from git config (same user as the template)
   - `.python-version` kept at 3.14 (current uv python)
   - `README.md`: title + one-liner + provenance line
6. **Gate** — `uv sync` (fresh lock for the new name) → `make check` (exit 0)
   → `make test` (6 passed). `uv run templapyze` →
   `Hello from templapyze to world!`.
7. **Rename correctness** — `rg -w tpl8 --hidden`: 2 hits in project files,
   both intentional provenance lines (pyproject `origin`, README).
8. **git** — `git init -b main`, first commit, tag `bootstrap-v0` (golden
   tree for the Phase D diff).

## Decisions and gotchas (feed these into the command)

- **`rg`/tooling skip hidden dirs by default** — `.agents/` is invisible
  without `--hidden`. The command's rename must not rely on default-visibility
  file walkers; the skill dir lives under a dot-directory inside the package.
- **Provenance hits = 2, not 1** — the checklist's "exactly one hit" assumed
  only the pyproject stamp; the README provenance line (design decision 3)
  adds a second. The rename-correctness test must exclude both provenance
  lines (or assert "no hits outside provenance locations").
- **Template fix made before the run** — the manifest's `files` was missing
  `tests/`; added in tpl8 commit `96a6a5d` and `v0.1.0` re-pointed (local
  tag). The vendored snapshot (Phase C) must come from the re-pointed tag.
- **`git archive` is the extraction primitive** — it copies only tracked
  files, so the exclusion list shrinks to `docs/` + `uv.lock` (everything
  else artifact-like is already gitignored upstream).
- **Content vs rename** — after the mechanical rename, SKILL.md, README, and
  AGENTS.md still describe a *greeter*. Rewriting them for the real tool is
  Phase C work; the project's own AGENTS.md guides that work.
- **Ordering constraint** — the manifest→provenance replacement happens
  *after* the token rename; doing it before would let the rename rewrite
  `origin = "tpl8"`.
